## About the Project

TechByCornelius is a React-based technology portfolio designed to present technical skills, development projects, and IT services through a publicly accessible web application.

The repository demonstrates experience working with modern JavaScript technologies, reusable components, version control, and cloud deployment configuration.

## Technology Stack

- **JavaScript** — Application programming and functionality
- **React** — Component-based user interface development
- **React Native / React Native Web** — Cross-platform application technologies
- **Expo** — React Native development tooling
- **GitHub** — Source control and project management
- **GitHub Actions** — CI/CD workflow configuration
- **Microsoft Azure** — Static Web Apps deployment configuration

## Project Structure

- `App.js` — Main application implementation
- `components/` — Reusable application components
- `assets/` — Project assets
- `public/` — Public web resources
- `.github/workflows/` — Automated deployment workflow configuration
- `package.json` — Project dependencies and scripts
